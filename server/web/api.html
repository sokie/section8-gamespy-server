JSON API

Read-only, no authentication. Every page of this site is built from these endpoints. Section 8 (2009) has the same endpoints under /api/s8/.

/api/gamesThe games this server keeps stats for, with their page prefix and art.
/api/summaryTotals: players, matches, servers online, kills, time.
/api/leaderboard?sort=xp&offset=0&limit=50Ranked players. sort is xp, kills, kd, time or matches; limit is at most 500.
/api/players?q=namePlayers whose name or GameSpy nick contains the text, or whose profileid is it. At most 50.
/api/players/<profileid>A full career: records, time per mode, badges, feats, unlocks, gear, the last 25 matches.
/api/serversDedicated servers with their published status, and whether they are online.
/api/s8/summaryThe same for Section 8 (2009), and so on for each endpoint.
