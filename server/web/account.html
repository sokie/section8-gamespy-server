How to claim your profile

  1. Create an account on this page and sign in.
  2. In Section 8: Prejudice, sign in to Prejudice Online, open Dropship, then Stats Portal. The game shows a code such as 758B-338A-154D.
  3. Enter the code under Claim a profile. The game makes a new code each time the Stats Portal screen opens, so enter the newest one.
  4. Set the display name and the clan tag of the profile. At its next sign-in, the game shows the profile as activated, with the new clan tag.
